# 🏦 Ebrahim Bank

A simple banking system built with **C#** to apply and practice my understanding of **Object-Oriented Programming (OOP)** through a practical project.

## Features

* **Encapsulation:** Controlled access to account balances and transaction data.
* **Inheritance & Polymorphism:** Different account types (`SavingsAccount` and `CurrentAccount`) with their own withdrawal behavior.
* **Abstraction:** An abstract `Account` class defining common account behavior.
* **Composition:** Customers manage accounts, and accounts maintain transaction history.
* **Enums:** Used for account and transaction types.
* **Validation:** Handles invalid customers, accounts, deposits, withdrawals, and transfers.
* **Banking Operations:** Deposit, withdrawal, transfer, account management, and transaction tracking.
* **Overdraft:** Support for overdraft limits in Current Accounts.

## How to Run

1. Open the project in **Visual Studio**.
2. Build the project.
3. Run `Program.cs` to see the banking system simulation.
